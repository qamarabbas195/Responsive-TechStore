# TechStore - Responsive Web Layout

## Project Overview
TechStore is a real-world responsive online technology store webpage. It is created for Frontend Development Project 2 and focuses on responsive web layout.

## Requirements Covered
- CSS media queries
- Responsive navigation
- Proper spacing and alignment
- Responsive CSS Grid
- Mobile hamburger navigation
- Desktop, tablet and mobile layouts

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in any modern web browser.

## Project Purpose
This project demonstrates how a webpage can smoothly adapt to different screen sizes using CSS media queries and responsive layout techniques.
